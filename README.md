# PetMatch AI

**Nome do Grupo:** 15 - Felipe Ramos; Vinicius Barboza; Davi Marins

**O que foi criado:** O PetMatch AI é uma aplicação web em Python + Streamlit que ajuda a reencontrar animais perdidos, usando o modelo de IA CLIP para comparar fotos e sugerir possíveis correspondências entre animais perdidos e encontrados.

**Quem vai utilizar:** Tutores que perderam um animal, pessoas que encontraram um animal na rua e ONGs ou abrigos de proteção animal.

**Como será usado:** O usuário cadastra um animal perdido ou encontrado (foto, características, data e local) ou envia uma foto na busca; o sistema mostra os registros mais parecidos, e a confirmação final da identidade deve ser feita por uma pessoa.
